# Máy Tính Giấy PWA (iOS & Android Offline)

Ứng dụng Web (PWA) chuyển đổi từ `tinh_dk_so met_trong luong_giay RE.py`, chạy mượt trên cả **iPhone (Safari)** và **Android (Chrome)** và hoạt động **offline**.

## Tính năng
- Tự động nội suy **HSĐK** theo **Định lượng** và **Loại Giấy** (`GIẤY XEO` / `GIẤY MÀU`), vẫn cho phép chỉnh tay trực tiếp.
- Tính **Số mét (m)** hoặc **Trọng lượng (kg)** kèm **Đường kính cuộn (cm)** với lõi cố định `Ø 100 mm`.
- Tự động lưu thông số đang nhập và **Lịch sử 50 lần tính gần nhất** vào `localStorage`.

## Đưa lên GitHub Pages
1. Tạo repository mới trên GitHub (chọn **Public**, ví dụ `tinh-cuon-giay`).
2. Kéo thả toàn bộ các file trong thư mục này lên nhánh `main` → **Commit changes**.
3. Vào **Settings → Pages** → **Source**: `Deploy from a branch` → **Branch**: `main` + `/ (root)` → **Save**.
4. Mở link `https://<username>.github.io/tinh-cuon-giay/` trên điện thoại và chọn **Thêm vào màn hình chính**.
